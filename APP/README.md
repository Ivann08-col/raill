Mini app creada en `APP/` para pruebas rápidas.

Para ejecutar:

1. Abrir terminal en `APP/`
2. Ejecutar:

```bash
npm install
npm run dev
```

La app usa Vite y React. Tiene componentes básicos: `Navbar`, `HomePage`, `Login` y `Register`.

Notas:
- Los campos de correo fuerzan minúsculas y no permiten pegar (onPaste prevented).
- Es una app de ejemplo autónoma; no integra el backend principal.
